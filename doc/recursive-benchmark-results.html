Selected aggregation tree

Each result covers six block arrivals, 12 seconds apart, at 0, 12, 24, 36, 48, and 60 seconds. At each arrival, all proofs for that block are supplied together; a root does not wait for proofs from later blocks. The unfinished-root count is measured at 72 seconds. A configuration is admitted when every measured root meets the selected input-to-root limit and no roots remain unfinished at 72 seconds. Ethereum inclusion of the root is outside this benchmark. Child proofs are prepared before timing starts. All serialized child proofs are counted as downloads. Each serialized root proof is counted once per recipient as an upload. The benchmark calculates network requirements from proof sizes; it does not transmit data over a network.
